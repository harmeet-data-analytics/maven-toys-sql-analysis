# Maven Toys SQL Analysis

## Project Overview
This project analyzes retail sales data using PostgreSQL to understand sales performance, revenue, profitability, product performance, store performance, and inventory.

## Tools Used
- PostgreSQL
- SQL
- GitHub

## Database Tables
- **Sales:** Transaction dates, products sold, stores, and units sold.
- **Products:** Product names, categories, costs, and selling prices.
- **Stores:** Store names, cities, locations, and opening dates.
- **Inventory:** Product stock available at each store.

## Key Business Questions
- What are the total sales, revenue, and profit?
- Which products and categories generate the highest revenue?
- Which stores perform best?
- How does monthly revenue change over time?
- Which products have never been sold?
- Which stores have missing inventory records?
- How do products and stores rank by sales performance?

## SQL Concepts Used
- JOINs and subqueries
- GROUP BY and HAVING
- Aggregate functions
- Common Table Expressions (CTEs)
- Window functions, including RANK and LAG
- CASE expressions and NULL handling

## Project Goal
To turn retail sales data into meaningful business insights using SQL and develop practical data analytics skills.
