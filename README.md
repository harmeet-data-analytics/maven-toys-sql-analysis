# Maven Toys SQL Analysis

## Project Overview
This project analyzes retail sales data from Maven Toys using PostgreSQL to identify business insights and understand sales performance.

## Tools Used
- PostgreSQL
- SQL
- GitHub

## Database Tables
- **Sales:** Contains sales transactions, dates, store IDs, product IDs, and units sold.
- **Products:** Contains product names, categories, costs, and selling prices.
- **Stores:** Contains store names, cities, locations, and opening dates.
- **Inventory:** Contains stock-on-hand information for products across stores.

## Key Business Questions
- What is the total revenue and profit?
- Which products perform best in sales?
- Which stores generate the most revenue?
- Which product categories perform well?
- How does sales performance change over time?
- What inventory insights can help business decisions?

## SQL Concepts Used
- SELECT and WHERE
- GROUP BY and HAVING
- Aggregate functions
- INNER JOIN and LEFT JOIN
- Subqueries and CTEs
- CASE and COALESCE
- Window functions
- Date functions and sales analysis

## Project Goal
To turn retail sales data into meaningful business insights using SQL and develop practical data analytics skills.
